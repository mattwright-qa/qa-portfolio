# Tallawah Billing demo rules

- Work only inside this fictional demo folder.
- Never request credentials, customer data, or production access.
- Before editing, state the failure and the evidence that supports it.
- Make the smallest change that fixes the confirmed behavior.
- Add or update a test that fails before the fix and passes after it.
- Do not weaken an expected result to make a test green.
- Stop after producing the diff and test output. A human decides whether it is accepted.
